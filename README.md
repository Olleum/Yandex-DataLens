Проект: Аналитическое исследование операционных показателей сервиса «Семейный бюджет»

Репозиторий с решением кейса: «Проектирование BI-системы мониторинга регистраций и финансовых транзакций в Yandex DataLens».

📌 Intro

Цель данного проекта — разработать комплексный дашборд для отслеживания динамики пользовательской активности и финансовых потоков сервиса. 

Работа включала в себя построение ETL-процесса для обработки сырых логов и визуализацию ключевых бизнес-метрик (регистрации, траты, средние показатели) для принятия управленческих решений.

🎯 Задачи проекта

Data Integration: Объединение данных о регистрациях пользователей и их транзакционной активности в единую модель данных.

Trend Analysis: Исследование помесячной динамики прироста аудитории и объема совершенных трат.

Metric Engineering: Расчет ключевых производных показателей (средний чек, суммарные расходы) для оценки эффективности сервиса.

Interactive UX: Реализация системы фильтрации (селекторов) для глубокого бурения данных (Drill-down) по временным периодам и категориям.

Reporting: Создание итоговой интерпретации данных в PDF-формате для презентации стейкхолдерам.

✅ Решение

Подготовка датасета: На основе CSV-файла (da_project02_data.csv) сформирована логическая схема данных. Проведена настройка типов данных: выделены временные шкалы (Month, Date) и финансовые показатели (Amount/Sum).

Мониторинг аудитории: Построена визуализация «Регистрации по месяцам», позволившая выявить сезонные колебания активности новых пользователей.

Финансовая аналитика: Реализован чарт «Траты по месяцам» для отслеживания динамики оборота средств внутри системы.

Scorecards (Индикаторы): Выведен блок «Основные метрики», отображающий агрегированные значения (Total Spend, Average Transaction, User Count) для мгновенного контроля состояния проекта.

Система фильтрации: Настроены интерактивные селекторы (даты, типы транзакций), обеспечивающие гибкость анализа для конечного пользователя.

Интерпретация результатов: Сформирован аналитический отчет (interpretation.pdf) с выводами по аномалиям и точкам роста сервиса.

📈 Результаты

Прозрачность данных: Создан единый «источник истины» (Single Source of Truth), позволяющий за секунды оценить финансовое здоровье сервиса без ручной обработки таблиц.

Выявление паттернов: На основе дашборда определены наиболее активные месяцы по привлечению пользователей и сопоставлены с объемами трат.

Масштабируемость: Архитектура дашборда позволяет подключать новые данные без пересборки визуализаций, обеспечивая автоматизированное обновление отчетности.
